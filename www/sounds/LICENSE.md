# 背景音来源与授权

所有背景音均为真实录音，取自开源项目 Moodist（https://github.com/remvze/moodist）的 public/sounds 目录。
按其说明，这些音频采用 **Pixabay Content License** 或 **CC0**，均允许商用、无需署名。

本目录文件经过处理：截取约 60 秒、做首尾交叉淡化以便无缝循环、统一响度、转 80kbps MP3。
部分为多条录音混合：
- forest 森林鸟鸣 = wind-in-trees + birds + woodpecker
- night-forest 夜晚森林 = crickets + wind-in-trees + owl
- pond 池塘蛙鸣 = frog + crickets
- rain-forest 林中雨 = rain-on-leaves + birds
- thunderstorm 雷雨 = heavy-rain + thunder
- seashore 海岸海鸥 = waves + seagulls
- deep-sea 深海鲸歌 = underwater + whale
- snow-fire 雪夜篝火 = howling-wind + campfire
